# Text-to-Avatar Generator

A web application that generates avatars based on text descriptions using DiceBear's API.

## Features

- Text input for avatar description
- Real-time avatar generation
- Responsive design
- Modern UI with React

## Tech Stack

- Frontend:
  - React
  - Vite
  - Styled Components
  - DiceBear API

## Getting Started

1. Clone the repository:
```bash
git clone [your-repo-url]
```

2. Install dependencies:
```bash
cd text-to-avatar/frontend
npm install
```

3. Run the development server:
```bash
npm run dev
```

4. Open your browser and navigate to `http://localhost:5173`

## Usage

1. Enter a text description in the input field
2. Click "Generate Avatar"
3. Your avatar will be displayed below the input field
